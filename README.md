# carmimRestSoap

<p> Criar uma arquitetura que integre rest e soap, implemente e documente uma API gateway.</p>
<ul>
  <li> Desenvolver ao menos um API Gateway </li>
  <li> Implementar o conceito de HATEOAS no Gateway </li>
  <li> Criar a documentação de API para o Gateway </li>
  <li> Implementar ou utilizar ao menos 2 API para simular a arquitetura interna de um sistema </li>
  <li> Desenvolver um Cliente Web para acessar o Gateway </li>
  <li> Desenvolver servidor e objeto(s) que, por meio de SOAP, será(ão) disponibilizado(s) pela rede </li>
  <li> Demonstre o arquivo WSDL gerado apresentando suas principais tags </li>
  <li> Desenvolver cliente(s) em linguagem(ns) diferente(s) do servidor detalhando a arquitetura utilizada e
como o cliente utiliza o WSDL para montar suas requisições </li>
</ul>

<p> O carmim é um aplicativo que tem o objetivo de monitorar o ciclo menstrual e acompanhar sintomas relacionados a endometriose utilizando inteligência artifial. Para essa aplicação em específico serão utilizadas as tecnologias: </p>
<ul>
  <li> API gateway - Node.js </li>
  <li> API rest - Django rest </li>
  <li> API soap com IA - Python com spyne </li>
  <li> Documentação rest - Swagger </li>
  <li> Cliente web - Vue.js </li>
  <li> Documentação - Swagger e Soap UI </li>
</ul>
